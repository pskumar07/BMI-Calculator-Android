📱 BMI Calculator - Android App
A simple Body Mass Index (BMI) Calculator Android app built using Android Studio and Kotlin/Java. The app calculates BMI based on user inputs and provides health insights based on BMI categories.

📌 Features
✔️ User-friendly UI with real-time BMI calculation
✔️ Input height (cm/ft) and weight (kg/lbs)
✔️ Display BMI results with health classification
✔️ Suggest health tips based on BMI category
✔️ Dark mode support (if implemented)
